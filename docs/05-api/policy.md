# Policy API

## Status

Deferred; not part of Release 1 Lead Management.

No Policy endpoint may be implemented from this placeholder. Before this API is
approved, documentation must define Policy identity, Customer and insurer
relationships, lifecycle states, issuance preconditions, dates, documents,
ownership, correction/cancellation rules, authorization, Timeline/Audit
effects, and the relationship to a `WON` Lead.

Release 1 must not create an incomplete Policy when a Lead becomes `WON`, and
`POLICY_ISSUED` must not be accepted as a Lead status.
